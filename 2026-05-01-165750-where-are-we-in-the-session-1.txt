  Path B — BLOCKED (Strike 1)

  Renode crashed at boot with:
  CPU abort [PC=0xA5A5A5A4]: Trying to execute code outside RAM or ROM

  0xA5A5A5A4 is the FreeRTOS stack-fill sentinel — a stack overflow caused by
  TinyUSB initializing the USBD peripheral (which Renode doesn't emulate), then
  branching to a garbage address.

  Root cause: #include "Adafruit_TinyUSB.h" at line 24 is unconditional. In the
  Renode path, TinyUSB is unused (only Serial1/UARTE0 is needed), but it still
  initializes and crashes.

  Fix required:
  // Line 24: guard TinyUSB include for hardware path only
  #ifndef CONFIG_CRUCIBLE_RENODE_SIM
  #include "Adafruit_TinyUSB.h"
  #endif

  Plus the Renode compile command must drop -DUSBCON -DUSE_TINYUSB flags.
